🥗 IF08 - Recette de la Salade César

  📖 Description du projet

Ce projet a été réalisé dans le cadre du module IF08 – Conduite d'un projet web simple.

L'objectif est de concevoir un site web statique présentant une recette de cuisine : la Salade César, tout en appliquant les principes de gestion de projet, de travail collaboratif et de développement web responsive.

Le site présente :

* La recette complète de la Salade César
* La liste des ingrédients
* Les étapes de préparation
* Les informations nutritionnelles des ingrédients
* Une interface responsive adaptée aux ordinateurs et aux appareils mobiles

---

  🚀 Technologies utilisées

* HTML5
* CSS3
* Bootstrap 5 (CDN)
* JavaScript
* JSON
* API OpenFoodFacts
* Git / GitHub

---

  🥬 Fonctionnalités

 # Affichage de la recette

* Présentation de la Salade César
* Liste des ingrédients
* Étapes de préparation détaillées

 # Informations nutritionnelles

Les données nutritionnelles sont récupérées à partir de l'API OpenFoodFacts.

Pour chaque ingrédient, le site peut afficher :

* Nom du produit
* Image du produit
* Nutri-Score
* Informations nutritionnelles principales

 # Calcul du Nutri-Score moyen

Le projet permet également d'exploiter les données récupérées afin d'obtenir une estimation globale de la qualité nutritionnelle de la recette.
